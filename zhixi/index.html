    为什么开粗会，精光反而难？
    开粗主要是高效去料；精光必须让刀具贴合曲面，同时处理陡峭面、平面、窄角、刀具半径、实际剩余料和刀柄避让。

      复制下面的问题给AI
      推荐的提问约束
      一次只讲下一组2~3个操作；每步写明菜单路径、中文/英文名称、预期结果和常见错误。无法确定界面版本时先要求截图；不猜测切削用量或发布可直接上机的程序。
      


      宏工坊：从真人操作中提取可重复的命令
      

      第一步：运行无副作用测试宏
      在 PowerMill 中选择 主页 → 宏 → 运行，或者在资源管理器的 宏（Macros） 节点右键选择运行，打开网站下载的文件：
      宏/00_连接测试_只弹提示.mac
      预期：弹出“ZhiXi V0.1 macro connection OK - training only.”的信息框；不会建立刀路、修改项目或生成NC程序。
      PowerMill 官方的录宏方法
      主页 Home → 宏 Macro → 录制 Record → 保存 .mac 文件 → 手动完成一项重复操作 → 再次按录制停止。

注意：如果某个输入框已经是目标值，也要重新输入一次，才能确保该值被记录到宏中。
      

      第二步：上传刚才录制的 .mac 文件分析
      文件只在浏览器本地读取；不会上传。解析结果只是初步风险提示，不代表宏已验证能安全执行。
      尚未选择文件。建议先录制“调整视角/显示隐藏模型”等不涉及机床动作的操作。
      // 示例：请在PowerMill内先亲自录制一段宏，然后导入分析。
      

      AI下一步能如何改写它？
      例如把每次都要重复选择的视角、模型显示方式、项目初始化步骤变成模板。但对于刀具选择、加工公差、工作平面、进给转速、后处理等与设备有关的值，必须在目标工件上重新确认。
      不得把网上下载、AI凭空编写或未经审查的宏，直接用于真实工件编程，更不能自动控制机床开始加工。

      环境准备与官方资料
      软件需要准备什么？
      PowerMill
      Windows 10/11 64位，安装合法授权软件或官方试用版；软件版本与界面语言在首页填写。
      本助手
      在线网站直接使用；本地离线版双击 index.html。
      学习模型
      模型/ZZ101_圆角型腔_100x80x20.step（优先）或 .stl（备用）。
      AI助手
      可用ChatGPT等具备图片理解的AI对话工具，配合PowerMill操作截图。无需API密钥。
      宏文件
      仅示范宏和人工录制的宏；不需要先安装PowerMill插件。
      官方2026系统配置参考：至少8GB内存、建议复杂工件16GB以上；多核64位处理器；按官方要求预留磁盘空间。安装许可和硬件按官方页面核实。
